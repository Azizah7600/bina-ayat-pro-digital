# BINA AYAT PRO DIGITAL
**Faham, Susun, Bina dan Semak**

Aplikasi web pendidikan untuk meningkatkan penguasaan tatabahasa bahasa Melayu dan kemahiran membina ayat gramatis dalam kalangan pelajar Sijil Vokasional Malaysia (SVM), Semester 1 hingga Semester 4.

**Pemilik inovasi:** Cikgu Azizah Ismail
**Institusi:** Kolej Vokasional Wakaf Tembesu

## Mula pantas
- **Cuba segera (Mod Demo):** buka `index.html` melalui pelayan web, atau terbitkan folder ini ke Netlify. Data mod demo hanya disimpan dalam pelayar.
- **Sistem rasmi:** ikut `docs/PANDUAN-DEPLOYMENT.md`, iaitu cipta projek Supabase, jalankan `supabase/schema.sql`, kemudian isi `js/config.js`.
- **Cara guna:** rujuk `docs/PANDUAN-PENGGUNAAN.md`.

## Teknologi
- Frontend: HTML, CSS dan JavaScript tanpa proses build, jadi mudah diselenggara dan boleh dihoskan di mana-mana hos statik.
- Backend: Supabase, iaitu PostgreSQL, Auth, Row Level Security dan trigger pengesahan kod akses.
- Hosting: Netlify, Railway atau GitHub Pages.

## Kandungan
- 6 modul × 3 tahap, dengan 361 soalan, nota, contoh, jawapan dan penerangan
- Ujian pra dan pasca setara (2 × 25 soalan, 100 markah)
- Pembelajaran pintar: rekod kesilapan mengikut topik, pengesanan topik lemah dan latihan pemulihan
- Gamifikasi: mata, tahap, 7 lencana, streak, cabaran mingguan dan sijil digital
- Dashboard guru: analisis, intervensi, semakan rubrik, kod akses, CSV, PDF dan sandaran JSON
